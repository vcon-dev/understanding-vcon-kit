# Walk Eleanor's four calls

Conversation graph session. Four conversations about one storm drain, January to March.

## Use it with any AI assistant

Copy this prompt into ChatGPT, Claude, Gemini, Copilot or any assistant that can read a web link:

```
Read these four vCons:
https://raw.githubusercontent.com/vcon-dev/understanding-vcon-kit/main/kit/graph/1-eleanor-pucci-2026-01-20-first-flood.vcon.json
https://raw.githubusercontent.com/vcon-dev/understanding-vcon-kit/main/kit/graph/2-eleanor-pucci-2026-02-10-second-flood.vcon.json
https://raw.githubusercontent.com/vcon-dev/understanding-vcon-kit/main/kit/graph/3-marcus-2026-02-12-crew-call.vcon.json
https://raw.githubusercontent.com/vcon-dev/understanding-vcon-kit/main/kit/graph/4-eleanor-pucci-2026-03-02-third-call.vcon.json

They are one resident's storm drain. Walk them in date order. List every promise made, who made it, whether it closed, and what is still open. When could someone have known the drain was not fixed?
```
