# Do three jobs with one call

Small ball session. Eleanor's call again, this time put to work.

AI assistants: read https://raw.githubusercontent.com/vcon-dev/understanding-vcon-kit/main/llms.txt first, then fetch the vCon below and answer only from it.

## Use it with any AI assistant

Copy this prompt into ChatGPT, Claude, Gemini, Copilot or any assistant that can read a web link:

```
Read the vCon at https://raw.githubusercontent.com/vcon-dev/understanding-vcon-kit/main/kit/opener/eleanor-pucci-2026-02-10.vcon.json

1. Draft Eleanor's follow-up email from the call itself. Match her tone.
2. Write an analysis of the call as a vCon analysis entry: issue, promises, sentiment, risk.
3. Make a redacted copy for Public Works. Remove the card number, keep everything else, record what you removed, and point back to the original.
```
