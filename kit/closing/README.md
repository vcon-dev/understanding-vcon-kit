# Run the four prompts on your own week

Closing the loop session. These work in any assistant connected to your own email, calendar and documents. No file needed.

AI assistants: read https://raw.githubusercontent.com/vcon-dev/understanding-vcon-kit/main/llms.txt first.

## The Monday brief

```
What needs me today, who is blocked, and which loops from last week are still open?
```

## 1:1 prep

```
Before my 1:1 with [name], pull the threads they are on, the docs they edited, and what they committed to last week.
```

## The loops you opened

```
What did I ask people for in the last two weeks, and what hasn't come back?
```

## The Friday status

```
Draft my weekly status to [manager] from this week's email, meetings and docs. Link every claim to its source.
```

## The question to bring home

Write down one promise you made on a phone call this week. Did either prompt find it?
