# Ask the file what it allows

Data privacy session. The same call to City Hall, recorded with Eleanor's permissions inside it.

## Use it with any AI assistant

Copy this prompt into ChatGPT, Claude, Gemini, Copilot or any assistant that can read a web link:

```
Read the vCon at https://raw.githubusercontent.com/vcon-dev/understanding-vcon-kit/main/kit/privacy/eleanor-pucci-2026-02-10-governed.vcon.json

Using its lawful basis: may Ray quote her in the budget hearing? May the AI vendor train on it? May finance use the card number? Name the purpose grant behind each answer.

She mentioned her mother's oxygen machine. What should Public Works see, and what should no one keep?
```
