# Understanding vCon training kit

Sample vCons and prompts for the Understanding vCon training morning. Each session's QR code opens its folder. Every file works with any AI assistant: paste the prompt, or download the file and upload it.

AI assistants: read [llms.txt](llms.txt) first ([raw](https://raw.githubusercontent.com/vcon-dev/understanding-vcon-kit/main/llms.txt)). It maps every field in the sample vCons to each role. [AGENTS.md](AGENTS.md) is the same file.

| Small ball | [kit/small-ball](kit/small-ball) |
| A network problem | [kit/network](kit/network) |

Presenter files for the Closing the Loop replay are in [presenter](presenter).

All files are synthetic. Every person and organization in them is illustrative, and card numbers are published test numbers. Format: vcon 0.4.0, text dialog, no analysis entries. The privacy and network files carry a lawful_basis attachment.
